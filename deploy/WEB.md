# เปิดหน้าเว็บของ Stark ผ่าน SSH tunnel (D-53, R-7)

หน้าเว็บของ Stark ฟังเฉพาะ `127.0.0.1:8080` บน VPS จึงเข้าจากอินเทอร์เน็ตตรง ๆ ไม่ได้ (D-38) วิธีเข้าคือเปิด
"อุโมงค์" SSH จาก Mac ไปที่ VPS แล้วเปิด browser บน Mac ที่ `http://localhost:8080` ข้อมูลระหว่าง Mac กับ VPS
วิ่งอยู่ในการเชื่อมต่อ SSH ซึ่งเข้ารหัสอยู่แล้ว

- คำสั่งที่ขึ้นต้นด้วย `mac$` ให้รันใน Terminal บน Mac โดยพิมพ์เฉพาะส่วนที่ตามหลัง `mac$`
- รันบน **Mac** เท่านั้น ไม่ใช่บน VPS
- คำสั่งข้างล่างใช้ `root@143.14.11.53` ถ้าตั้งชื่อย่อ `stark` ไว้ใน `~/.ssh/config` แล้ว (`deploy/SETUP.md` ส่วนต้น)
  ใช้ `stark` แทนได้ ถ้ายังไม่ได้ตั้งแต่พิมพ์ `stark` จะขึ้นว่า `Could not resolve hostname stark`
- บนมือถือให้ใช้คำสั่ง Telegram แทน ซึ่งทำได้เหมือนกัน (D-53)

---

## 1. เปิดอุโมงค์

```
mac$ ssh -N -L 8080:127.0.0.1:8080 root@143.14.11.53
```

- `-L 8080:127.0.0.1:8080` แปลว่าส่งพอร์ต 8080 บน Mac ไปที่ `127.0.0.1:8080` บน VPS
- `-N` แปลว่าไม่ต้องเปิด shell ให้ทำแค่อุโมงค์อย่างเดียว

คำสั่งนี้จะค้างไว้โดยไม่แสดงอะไร **แบบนี้ถูกต้องแล้ว** อย่าปิดหน้าต่างนี้ตอนที่ยังใช้หน้าเว็บอยู่

ถ้าขึ้นว่า `bind [127.0.0.1]:8080: Address already in use` แปลว่ามีโปรแกรมอื่นบน Mac ใช้พอร์ต 8080 อยู่ ให้ใช้พอร์ตอื่น
เช่น `mac$ ssh -N -L 18080:127.0.0.1:8080 root@143.14.11.53` แล้วเปิด `http://localhost:18080` แทน

## 2. เปิดหน้าเว็บ

1. เปิด **Chrome** หรือ **Firefox** บน Mac แล้วพิมพ์ `http://localhost:8080`
   - ต้องเป็น `http` (ไม่มี s) และต้องเป็น `localhost`
   - อย่าใช้ `127.0.0.1` เพราะ browser บางตัวไม่เก็บ cookie เข้าระบบ (`Secure`) ให้ที่อยู่นั้น
2. ใส่รหัสผ่านเจ้าของ (ตัวที่ใช้สร้าง hash ใน `OWNER_PASSWORD_HASH`) แล้วกด **เข้าสู่ระบบ**
3. ต้องเห็นส่วน "ราคาล่าสุด", "กฎแจ้งเตือน", "ช่องทางแจ้งเตือน", "สุขภาพระบบ" และ "การแจ้งเตือนย้อนหลัง 24 ชั่วโมง"
   Telegram จะแจ้งว่ามีการเข้าสู่ระบบทุกครั้ง ถ้าเห็นข้อความนี้ตอนที่ไม่ได้เข้าเอง ให้เปลี่ยนรหัสผ่านทันที (T-22)
4. ลองกดรีเฟรช (⌘R) ต้องยังอยู่ในระบบ ถ้าเด้งกลับมาหน้าใส่รหัสผ่าน แปลว่า browser ไม่เก็บ cookie
   ให้ลองใช้ Chrome แทน แล้วแจ้ง Claude ว่าใช้ browser อะไร รุ่นไหน
   - Safari ยังไม่ได้ทดสอบ ถ้าจะใช้ Safari ให้ลองข้อ 4 นี้ก่อน

ถ้าใส่รหัสผิด 5 ครั้งภายใน 15 นาที ระบบจะล็อกการเข้าไว้ 15 นาทีและแจ้งทาง Telegram ให้รอจนครบ 15 นาทีแล้วลองใหม่

## 3. เลิกใช้

1. กด **ออกจากระบบ** มุมขวาบน
2. กลับไปที่หน้าต่าง Terminal ที่เปิดอุโมงค์ไว้ แล้วกด `Ctrl+C` อุโมงค์จะปิด และ `localhost:8080` จะใช้ไม่ได้อีก
   จนกว่าจะเปิดอุโมงค์ใหม่

ถ้าไม่กดออกจากระบบ การเข้าระบบนั้นจะหมดอายุเองใน 7 วัน

## เมื่อเปิดไม่ได้

| อาการ | สาเหตุที่น่าจะเป็น | ทำอย่างไร |
|---|---|---|
| browser ขึ้นว่า "This site can't be reached" | อุโมงค์ไม่ได้เปิด หรือปิดไปแล้ว | ทำข้อ 1 ใหม่ |
| หน้าต่างอุโมงค์ขึ้น `channel 2: open failed: connect failed: Connection refused` | Stark ไม่ได้รันอยู่บน VPS | `vps# systemctl status stark` แล้วส่งผลมาให้ Claude |
| เข้าได้ แต่รีเฟรชแล้วหลุด | browser ไม่เก็บ cookie `Secure` ที่ `http://localhost` | ใช้ Chrome หรือ Firefox และพิมพ์ `localhost` ไม่ใช่ `127.0.0.1` |
| ขึ้น `LOGIN_LOCKED` | ใส่รหัสผิด 5 ครั้งภายใน 15 นาที | รอ 15 นาทีแล้วลองใหม่ |
| ใส่รหัสที่คิดว่าถูก แต่ขึ้น "รหัสผ่านไม่ถูกต้อง" | hash ใน `OWNER_PASSWORD_HASH` สร้างจากรหัสอื่น | ระวังอย่าลองเกิน 4 ครั้ง แล้วแจ้ง Claude เพื่อสร้าง hash ใหม่ |
